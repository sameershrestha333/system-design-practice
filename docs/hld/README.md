# High-Level Design Notes

Learning notes and architecture diagrams for HLD practice.

See the [HLD roadmap](../../README.md#hld-roadmap) and [case studies](../../README.md#hld-case-studies) for the planned topics.

## Planned Organization

- `fundamentals/` — requirements, estimation, networking, and distributed systems.
- `building-blocks/` — databases, caching, load balancing, queues, and reliability.
- `case-studies/` — end-to-end system designs and their tradeoffs.

These folders will be added as notes are written.

## Case Study Outline

1. Requirements and assumptions
2. Traffic and storage estimates
3. APIs and data model
4. Architecture diagram and request flow
5. Scaling and bottlenecks
6. Failure handling and reliability
7. Alternatives, tradeoffs, and lessons learned

Save editable Excalidraw diagrams alongside the relevant notes, with an exported image for easy viewing on GitHub.
